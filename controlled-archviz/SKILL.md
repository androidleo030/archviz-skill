# 建筑效果图 Skill V0.1

## 触发与依据

用户显式调用 `$controlled-archviz`，或要求按 V2.1 建模、制作或复核受控建筑效果图，或在受控交付中接续既有模型或机位时使用。单纯的自由概念生图、通用 SketchUp 操作和商品检索不自动触发。

开始前读取[受控交付标准 V2.1（公开版）](references/standard-v2.1.md)。这是唯一规范，流程和模板用于执行该标准。缺少原文时暂停按 V2.1 执行。可按用户要求从任一阶段切入，先核查该阶段所依赖的已有成果。

## 接手与暂停

- 确认项目范围、所需交付物、机位及现用设计依据和版本。寻找现有 SKP、项目记录、家具样本、截图、索引卡、生成图和验收记录。
- 有记录时直接核对现用模型及文件，按可验证成果确定续作起点。无记录时由已有证据重建检查状态。复用已通过且仍对应当前输入的工作。从最早受变化影响的阶段继续，保留其他机位和构件的有效成果。
- 关键依据缺失或冲突时，记下依据、对象、受影响阶段或机位和需用户决定的事项。暂停受影响部分的正式作业，可继续独立部分。暂定数据标明待确认。B 级规格或可用产品图片缺失、原图和索引机位不一致、必要输入无法实际提供给生图工具时，暂停受影响机位的正式生图。
- 每次完成阶段或停在问题处，更新[续作记录](references/checkpoint.md)。相机变化后重新制作该机位索引并核对截图。模型或产品样本变化时复核依赖它的机位与已有验收结果。

## 分阶段执行

1. **G1 核验底图**。按第一、五章核对范围、图纸版本、单位、比例、坐标、墙柱及门窗等定位。
2. **G2 核验白模**。按图核对空间轮廓、墙体连接、洞口、楼板和主要固定构件。复用符合要求的现有几何。
3. **G3 装修与家具**。A级按设计依据建模并锁定。定制柜、定制前台和固定装修按施工资料处理。B 级按[家具样本卡](references/furniture-sample-card.md)登记用户指定或确认的产品。以真实长宽高和必要功能尺寸简化建模，保留主要外形、数量、方向、位置与占地。布置发生冲突时报告并等待决定。C 级按第 2.3 节处理。
4. **G4 绑定语义与样本**。构件语义仅写入 `Component ID`、`Name`、`Geometry Lock`。名称可以包含已确认的材料和构件类型。核对 A 级材料语义和 B 级产品、尺寸及图片。优先使用模型内属性。读写不稳定时按第 3.3 节使用与构件 ID 对应的外部材料清单。
5. **G5 固定相机与索引**。按[同机位索引卡](references/same-view-index-card.md)整理干净截图、同机位编号图、说明及对应产品图片。编号对应可见对象，活动家具按型号或类型关联。禁止逐像素蒙版。
6. **正式生图**。以对应模型截图和索引资料控制画面，实际随请求附上产品图片及对应编号。必要时合并参考图，保留关键控制信息和各产品的可辨识度。保持第六章规定的几何、材料、家具和布置约束。可优化光影、纹理、玻璃反光表现和室外贴图，须遵守已确认设计。
7. **验收与交付**。按[验收模板](references/acceptance.md)对照模型、同机位资料、产品样本和生成图。透视图无法核实的尺寸用模型和产品规格复核。按 V2.1 处理 P0/P1/P2 并保留证据。按第十一章和约定范围交付。

## 按交付范围执行

- **单机位图片**。完成该机位核验，保留原截图、同机位索引、样本和效果图。仅交付单机位图片时，B 级家具的图像视觉优化无需回写模型。
- **多机位图片**。复用同一模型和产品样本，分别建立机位资料与验收记录。跨机位核对建筑结构、固定装修及家具数量、位置、材料、主要造型和产品身份，结合各机位可见范围判断。按第 7.2 节处理已核实一致的非关键家具，并说明几何可验证性限制。
- **同时交付模型**。按第 7.3 节核查已确认的主要家具和固定装修在模型中的对应成果。

## Windows / SketchUp MCP

从当前会话实际提供的工具说明确认能力和参数。调用前核对活动模型和保存状态，避免把操作落在另一个打开的文件。能力未验证时，先用已有 SKP、截图、手工索引等可核查资料推进，或列出缺失输出并暂停受影响步骤。每次操作以实际输出核实结果。`scripts/` 中的待办仅供维护。
