# B 级家具样本卡

每个型号及已确认规格款式使用一张卡。同型号实例共享已核实的规格及图片。定制柜等固定家具按 V2.1 的设计依据处理。

| 项目 | 记录 |
| --- | --- |
| 样本编号 / 家具名称 | |
| 产品型号、规格款式 | |
| 样本来源（链接、手册页或用户资料） | |
| 用户指定或确认记录 | |
| 真实长 × 宽 × 高（含单位） | |
| 重要功能尺寸（含单位，如适用） | |
| 尺寸证据（规格页或文件） | |
| 颜色、材质、主要外形（按样本） | |
| 产品图片文件及对应型号、款式 | |
| 关联模型实例、数量、位置和方向 | |
| 布置冲突或待确认事项 | |

核对规格来源与图片是否对应同一款。用真实尺寸建立简化几何。在同机位资料中关联样本编号，正式生图时实际附上产品图片。商品链接可作为来源。缺少可靠尺寸或可用产品图片时记入续作记录，暂停受影响机位的正式生图。
