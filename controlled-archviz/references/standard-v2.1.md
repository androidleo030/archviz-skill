# AI 建模与建筑效果图受控交付标准 V2.1（公开版）

**适用范围：** 建筑室内外效果图、建筑空间可视化、装修效果图及 AI 辅助三维建模项目。

**当前技术路线：** AutoCAD图纸 → SketchUp + MCP → 受控三维模型 → 设计语义与产品样本 → 相机视角索引卡 → AI 辅助生图 → 成果校核与交付。

**标准性质：** 内部工作流程与成果质量控制标准，不代替国家设计规范、工程技术审查及专业人员责任。

**核心原则：设计依据决定建筑与固定装修，产品样本决定活动家具，模型决定空间几何，语义索引决定材质表达，AI 在允许范围内提升视觉质量。**

---

## 第一章：设计依据管理

### 1.1 图纸分类及用途

| 资料类型     | 主要控制内容            |
| -------- | ----------------- |
| 建筑平面图    | 外墙、隔墙、柱、门窗、空间轮廓   |
| 家具布置图    | 家具数量、位置、方向、原始布置意图 |
| 装饰立面图    | 墙面造型、固定家具、材料分区、高度 |
| 天花布置图    | 吊顶几何、标高、灯具及设备位置   |
| 地面铺装图    | 地面材料、颜色、分区及铺装关系   |
| 材料说明与节点图 | 材料名称、规格、厚度、细部做法   |
| 家具产品样本   | 活动家具真实尺寸、款式、颜色及材质 |
| 设计确认记录   | 设计变更、待确认内容及最终决定   |

不同类型的设计资料承担不同的控制职责，不能简单使用一种资料覆盖其他资料的全部内容。

### 1.2 设计依据优先原则

1. 已确认的设计数据优先于 AI 推测。
2. 明确尺寸优先于图片视觉比例。
3. 正式施工图及经确认的设计变更优先于概念参考图。
4. 普通活动家具以用户指定的产品样本为准，装饰布置图中的家具尺寸不作为绝对标准。
5. 定制柜、定制前台和固定装修构件以装饰立面、节点及确认变更为主要依据。
6. 不同设计依据存在矛盾时，记录冲突，暂停受影响部分的最终建模与交付。
7. 对缺失的尺寸和材料，可以建立暂定参数，但必须与已确认数据区分。

**禁止 AI 将自行生成的概念效果图作为改变既有施工图的理由。**

## 第二章：三维模型分级控制

### 2.1 A级：几何与设计完全锁定

适用对象：

- 外墙、隔墙、柱、梁、楼板
- 门窗洞口及位置
- 已明确设计的吊顶造型
- 有施工立面的定制家具
- 固定装修造型
- 具有明确尺寸、位置及材料要求的构件

控制规则：

- 不得改变已确认的位置、尺寸、数量及基本形状。
- 不得因摄影构图调整真实建筑尺寸。
- 不得将既定材料替换为另一种材料。
- 可以在不违反设计要求的情况下改善材质纹理、光影及视觉真实感。

**A级构件必须在 SketchUp 模型中存在，并能通过几何信息验证。**

### 2.2 B级：产品样本锁定、简化建模

适用对象：

- 普通活动桌椅
- 非定制沙发
- 普通活动柜
- 成品床、办公家具
- 未按装饰施工图专门定制的其他活动家具

**产品样本是 B级家具的主要设计依据。**

#### 产品样本要求

正式效果图中出现的 B级家具，必须具有明确的产品样本。

允许的产品来源：

- 淘宝、京东等商品链接
- 品牌官方产品页面
- 厂家产品手册
- 用户提供的实物照片及规格资料
- 其他能够明确识别产品款式的资料

用户指定或确认的样本优先。

产品样本应尽量包含款式、实际规格、颜色、材质和清晰的产品图片。

商品链接可以作为样本来源，但在正式生图前，必须取得可供生图模型使用的参考图片。

缺少可靠尺寸时必须记录待确认事项，不得直接根据照片推算精确尺寸。

#### 建模要求

SketchUp 中的家具以最小必要精度建模：

- 使用产品真实长、宽、高。
- 保留重要功能尺寸。
- 保留家具数量、位置、方向和占地关系。
- 只建立能够表达尺寸与主要外形的简化模型。
- 不要求精细建模五金、缝线、木纹、复杂曲面等视觉细节。

**不得因为模型库缺少精美家具，就要求 AI 建立复杂的高精度家具模型。**

#### 生图要求

正式生图时必须附带相应产品图片。

AI 应参考产品样本表现家具的款式、颜色、材质和造型，而不是根据简化模型重新设计家具。

允许优化光照、表面真实感及非关键细节。

不得擅自改变已确认产品的基本结构、数量、尺寸和功能。

如果产品真实尺寸与原平面布置冲突，必须报告，不能自行缩放家具或改变建筑尺寸。

### 2.3 C级：视觉装饰自由

适用对象：

- 书籍
- 玩具
- 小型植物
- 花瓶
- 装饰摆件
- 未明确规定的部分软装细节

允许 AI 进行合理增加、替换和美化。

但不得遮挡门窗、消防设施及必要通道，不得改变已经确认的房间功能，也不得与明确的设计要求冲突。

## 第三章：设计语义层

### 3.1 目的

解决三维模型只有几何形状，却缺少构件设计含义的问题。

因此，效果图生成时，必须同时使用几何信息和设计语义信息。

### 3.2 语义信息结构

采用精简属性结构：

| 字段            | 说明        |
| ------------- | --------- |
| Component ID  | 构件的唯一识别标识 |
| Name          | 构件名称      |
| Geometry Lock | 几何锁定等级    |

不强制为每个构件建立大量额外属性。

### 3.3 语义信息存储

优先采用 SketchUp 模型内置属性。

利用 SketchUp 属性字典或组件属性，将设计语义与真实构件关联。

在当前环境中验证属性写入、保存、重新打开及读取，确认构件编号与材料对应。

当模型属性无法稳定写入或读取时，可以采用与构件 ID 对应的外部材料清单作为备用方式。

## 第四章：相机视角索引卡

### 4.1 索引目的

生图模型无法直接读取 SKP 文件中的内部属性，因此由主模型负责提取设计信息，转换成生图模型能够理解的资料。

采用：

**同机位模型截图 + 同机位编号索引图 + 索引说明 + 产品样本图片。**

### 4.2 索引生成原则

固定 SketchUp 相机后，识别当前视角中需要控制的主要可见构件。

索引对象包括：

- 墙面
- 地面
- 天花
- 固定装修
- 定制家具
- 主要活动家具

对于墙面、地面、天花及固定装修，按需要独立控制的材料面建立索引。

相同材料且控制要求一致的连续面可合并索引；不同材料、颜色或造型应独立编号。

活动家具按产品型号或类型关联产品样本，不要求对每个家具子面分别编号。

普通装饰品原则上不单独建立索引。

**不采用逐像素构件蒙版作为常规工作流程。**

### 4.3 索引卡要求

索引卡应能够明确表达：

- 构件编号
- 构件名称
- 材料或产品身份
- 对应的位置或造型
- 必要的设计限制

编号不得严重重叠或产生歧义。

索引不应破坏原模型，也不应成为最终交付图片的一部分。

### 4.4 家具产品索引

同型号家具可以共享一份产品样本。

产品样本应关联到同机位画面中对应的家具类型。

## 第五章：建模阶段工作要求

### G1：建筑底图验证

根据 CAD、PDF 等资料确认模型范围。

必须核查：

- 图纸单位及比例
- 墙体和柱子位置
- 门窗数量及定位
- 图纸坐标与模型坐标
- 影响空间的主要结构构件

已知关键尺寸建议采用不大于5mm的内部误差目标；对于精确坐标转换的构件，应尽可能与源数据保持一致。

该阈值是内部工作目标，不是国家规范要求。

### G2：建筑白模验证

建立真实、可编辑的建筑三维模型。

必须检查空间轮廓、墙体连接、门窗洞口、楼板及主要固定构件。

不得为了生成更好看的效果图省略或移动关键建筑构件。

### G3：装修与家具模型

按照家具平面、装饰立面、天花及地面资料完善模型。

- A级构件建立与设计图纸对应的实际几何。
- B级家具采用产品样本尺寸的简化模型。
- C级装饰采用简化模型或后期视觉补充。

不要求全部家具都具有精细外观模型。

### G4：设计语义与样本绑定

正式生图前：

- 检查 A级构件的材料语义；
- 检查 B级家具的产品样本；
- 检查家具模型尺寸与产品规格；
- 确认缺失材料、缺失产品样本及尺寸冲突。

缺少必要设计依据的部分不得标记为已经完成。

### G5：相机视角索引

固定正式交付相机，导出干净截图及编号索引图，整理当前视角的材料和产品参考资料。

## 第六章：受控效果图生成

### 6.1 输入资料

每次正式生图至少提供：

1. 固定机位的 SketchUp 原始截图；
2. 同机位的构件编号索引图；
3. 对应的材料及构件说明；
4. 当前画面主要活动家具的产品样本图片；
5. 必要的设计限制及材质参考。

如果生成接口限制输入图片数量，应优先保留模型截图、关键索引和产品样本，合理合并参考资料，不得遗漏关键控制信息。

### 6.2 机位与空间关系

必须保持：

- 主要建筑结构；
- 空间比例；
- 主要家具的位置与数量；
- 重要固定装修造型；
- 门窗及固定设备的关系。

不得通过生成式 AI 擅自扩大房间、增高层高或改变家具间距。

### 6.3 图像增强权限

允许优化：

- 材质纹理及表面细节
- 自然光与人工光表现
- 阴影及反射质量
- 曝光、白平衡、环境氛围
- 非关键装饰细节
- 符合产品样本的家具真实感
- 玻璃反光表现，室外贴图

禁止未经确认修改：

- A级构件的几何和材料类型
- B级家具的产品款式及真实规格
- 主要家具的位置、数量和功能尺寸
- 既定地面、墙面及天花材料
- 结构关系和必要通道
- 已确定的颜色及材料分区

## 第七章：单视角与多视角交付

### 7.1 单视角交付

当项目只要求一个固定视角，且不要求交付精细家具模型时：

- A级构件必须与模型一致。
- B级家具必须符合对应的产品样本。
- C级装饰允许适当自由发挥。
- B级家具的最终视觉优化结果不强制回写 SketchUp 模型。

必须保留原始机位截图、索引资料和最终效果图，以便核查。

未回写模型的家具不能宣称已经完成精细三维建模。

### 7.2 多视角交付

当同一房间要求多个视角：

- 建筑结构与固定装修必须一致。
- 同型号家具使用相同的产品样本。
- 家具数量、位置、材料和主要造型应保持一致。
- 不得在不同视角中生成明显不同的产品。

优先复用相同的几何模型及产品样本。

若 AI 能够通过核查保持视觉一致性，不强制回写全部非关键家具，但应明确几何可验证性受到限制。

### 7.3 三维模型交付

当客户要求交付与效果图一致的完整三维模型时：

最终效果图中已经确认的主要家具和固定装修造型，应在三维模型中具有对应成果。

仅存在于生成图片中的造型，不能冒充已完成的精细三维模型。

## 第八章：模型与效果图对照验收

每个正式交付视角内部保留：

- SketchUp 原始相机截图
- 同机位编号索引图
- 对应的设计语义记录
- 对应的家具产品样本
- 最终效果图
- 检查结果及未解决问题

对照检查重点：

| 检查对象   | 核查要求                |
| ------ | ------------------- |
| 墙、柱、门窗 | 位置、数量及可见轮廓一致        |
| 固定家具   | 造型、尺寸关系和材料一致        |
| 活动家具   | 产品款式、数量、位置、真实规格符合约束 |
| 天花     | 轮廓、造型数量、标高关系符合依据    |
| 地面     | 材料类型、颜色和铺装分区正确      |
| 墙面材料   | 与装饰立面及索引信息一致        |
| 多视角表现  | 不存在明显结构或产品款式矛盾      |

透视图片无法直接验证的尺寸，应通过 SketchUp 模型数据及产品规格复核。

## 第九章：质量问题与处理

### P0：重大问题，禁止交付

- 墙体、柱子或门窗位置发生错误。
- AI 改变已确定的建筑空间尺寸。
- 主要家具数量、位置或功能尺寸错误。
- 已确认的产品被擅自替换为另一种产品。
- 已锁定的吊顶或固定装修造型被改变。
- 已指定的材料类型被替换。
- 多视角存在重大结构矛盾。

### P1：需修正后交付

- 家具外观与确认的产品样本明显不符。
- 定制柜分格或细部明显不符。
- 主要材质纹理错误。
- 构件与效果图细节存在明显差异。
- 产品样本或材料索引对应错误。

### P2：一般视觉优化

- 轻微材质瑕疵
- 非关键摆件协调性问题
- 局部阴影和反射不理想
- 不影响设计表达的图像瑕疵

P0问题未解决时，不得通过最终验收。

## 第十章：质量评分

| 验收项目           |       权重 |
| -------------- | -------: |
| 建筑几何与平面一致性     |      30分 |
| 固定装修与设计语义一致性   |      25分 |
| 家具产品样本及空间约束一致性 |      15分 |
| 视觉质量和摄影表现      |      20分 |
| 文件及核查记录完整性     |      10分 |
| **总计**         | **100分** |

**90～100分：** 达到内部受控交付质量目标。

**80～89分：** 基本合格，完成指定问题修正后可交付。

**80分以下：** 不通过受控交付验收。

存在 P0 问题、无法核实的关键设计条件和其他重大缺陷时，不能用视觉质量高分抵消。

## 第十一章：最小交付成果

根据项目要求确定对外交付范围，不强制每个项目交付全部成果。

### 必须内部保留

- 原始设计依据及版本
- 可编辑建筑空间模型
- 已确认的材料语义和家具样本资料
- 每个正式机位的模型截图
- 相应的材料索引卡
- 最终效果图
- 质量检查及修改记录

### 根据需求交付

- 正式效果图
- 平面及轴测展示图
- 材料说明
- 可编辑 SKP 模型
- 构件及家具清单

单视角图片项目可以不交付完整家具模型，但不得将未完成的内容宣传为完整三维设计成果。

## 第十二章：自动化与实施要求

Codex / Work 执行本标准时，应遵守：

**读取设计依据 → 建立建筑模型 → 核查尺寸 → 选择并确认家具产品样本 → 简化家具建模 → 绑定设计语义 → 固定相机 → 生成索引卡 → 准备产品图片 → 受控生图 → 对照检查 → 修正或交付。**

自动化执行原则：

1. 不重复建模已经存在且符合要求的构件。
2. 不强制精细建模普通活动家具。
3. 不强制执行逐像素蒙版生成。
4. 不为未出现在当前视角中的无关构件制作生图资料。
5. 相同产品型号复用同一份样本。
6. 相机改变后重新生成相应索引。
7. 已通过检查的设计依据和数据尽量复用。
8. 关键条件冲突时暂停受影响的操作。
9. 所有重大修改应可追溯。
10. 对不符合要求的成果提出具体修正项，不能仅反复生成。

---

## 第十三章：工具能力验证

以下能力应在实际环境中验证：

1. 自动识别当前相机视角中的重要可见构件。
2. 相机变化后的自动索引准确性。
3. 产品链接、产品尺寸及参考图片的自动提取能力。
4. 简化家具模型与产品图片的受控生成一致性。
5. 多视角生成时同一产品的外观稳定性。
6. AI 严格保持 A级构件几何及材料的能力。
7. 自动比较模型截图与效果图并识别重大偏差的准确性。
8. 不同项目之间复用该工作流的稳定性和性能表现。

尚未验证的能力不能视为已经实现。

## 最终原则

**一、建筑和固定装修必须准确。**

建筑空间、固定装修造型及明确的设计材料必须遵守设计依据。

**二、普通家具以真实产品为准。**

活动家具以用户确认的产品样本决定外观和实际规格，以 SketchUp 简化模型控制空间关系。

**三、模型不追求无意义的复杂度。**

只建立能够保证空间、尺寸及必要造型的几何，不为美化目的强制精细建模每一件家具。

**四、设计语义通过索引卡传递。**

主模型负责读取 SketchUp 的设计信息，使用当前相机的原始截图、索引卡和产品照片向生图模型表达设计意图。

**五、允许视觉优化，不允许随意修改设计事实。**

光影、纹理和非关键装饰可以优化；重要几何、材料和产品不得擅自更改。

**六、模型回写取决于交付目标。**

单视角图片交付不强制同步非关键家具的最终外观；模型交付和严格多视角一致性要求更完整的建模与核查。

**七、所有生成成果必须经过验证。**

商业视觉质量不能代替几何一致性、材料准确性和产品样本匹配。
